## 🚀 Features

| **Feature** | **Description** |
|:---|:---|
| **Atelier Browser** | Browse clothing items available across all installed Virtual Ateliers |
| **Outfit Planner** | Assemble and save outfit combinations from atelier items |
| **Style Tags** | Tag and filter items by style, color or atelier brand |
| **Wishlist** | Mark items to buy next time you visit your in-game ateliers |
